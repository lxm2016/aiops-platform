## 二、后端部署

### 2.1 环境要求
- Python 3.9+
- 建议独立服务器或虚拟机（2核4G以上）

### 2.2 安装步骤

```bash
cd backend
python -m venv venv

# Windows
venv\Scripts\activate
# Linux
source venv/bin/activate

pip install -r requirements.txt
```

### 2.3 配置

复制并编辑环境变量文件：

```bash
# 创建 .env 文件（在 backend 目录下）
```

`.env` 内容：

```ini
# 数据库（默认SQLite，生产环境建议MySQL）
DATABASE_URL=sqlite+aiosqlite:///./aiops.db
# MySQL示例:
# DATABASE_URL=mysql+aiomysql://aiops:password@127.0.0.1:3306/aiops

# 认证密钥（务必修改）
SECRET_KEY=your-random-secret-key-here

# Agent上报令牌（与agent/config.yaml中一致）
AGENT_TOKEN=aiops-agent-shared-token

# 千问大模型（OpenAI兼容API）
LLM_BASE_URL=http://192.168.1.100:8000/v1
LLM_API_KEY=EMPTY
LLM_MODEL=qwen2.5
```

### 2.4 启动

```bash
# 开发模式
python -m uvicorn app.main:app --host 0.0.0.0 --port 8080 --reload

# 生产模式（Linux建议用systemd管理）
python -m uvicorn app.main:app --host 0.0.0.0 --port 8080 --workers 2
```

启动后访问 `http://localhost:8080/docs` 查看API文档。

默认管理员账号：**admin / admin123**（首次登录后请修改）

## 三、前端部署

### 3.1 开发模式

```bash
cd frontend
npm install
npm run dev
# 访问 http://localhost:5173
```

### 3.2 生产部署

```bash
npm run build
# 将 dist/ 目录部署到 Nginx
```

Nginx 配置示例：

```nginx
server {
    listen 80;
    server_name aiops.yourcompany.com;

    location / {
        root /opt/aiops/frontend/dist;
        try_files $uri $uri/ /index.html;
    }

    location /api/ {
        proxy_pass http://127.0.0.1:8080;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }
}
```

## 四、Agent 部署（被监控服务器）

### 4.1 Linux

```bash
# 1. 将 agent/ 目录复制到目标服务器
scp -r agent/ root@192.168.1.50:/opt/aiops-agent/

# 2. 安装依赖
cd /opt/aiops-agent
pip3 install -r requirements.txt

# 3. 修改配置
vi config.yaml
# 将 server_url 改为: http://平台服务器IP:8080/api/servers/report

# 4. 测试
python3 agent.py --once

# 5. 设置开机自启（systemd）
cp systemd/aiops-agent.service /etc/systemd/system/
# 修改service文件中的WorkingDirectory和ExecStart路径
systemctl daemon-reload
systemctl enable --now aiops-agent
```

### 4.2 Windows

```powershell
# 1. 将 agent/ 目录复制到目标服务器，如 C:\aiops-agent\
# 2. 安装 Python 3.8+（Windows 2008 用 3.8）
# 3. 安装依赖
pip install -r requirements.txt
# 4. 修改 config.yaml 中的 server_url
# 5. 测试
python agent.py --once
# 6. 用 NSSM 注册为服务（推荐）或用任务计划程序开机启动
```

## 五、VMware 接入

1. 登录平台 → VMware管理 → 添加vCenter
2. 填写 vCenter/ESXi 地址、用户名、密码
3. 点击"同步"拉取虚拟机清单
4. 后续可配置定时自动同步

## 六、网络设备接入（SNMP）

1. 确保交换机开启SNMP：
   - **华为**: `snmp-agent community read public`
   - **华三**: `snmp-agent community read public`
   - **Dell**: 通过Web管理界面开启SNMP
2. 平台 → 网络设备 → 添加设备，填写IP和SNMP community
3. 点击"轮询"测试连通性
4. 系统每2分钟自动轮询所有网络设备

## 七、动环设备接入（Modbus TCP / RTU over TCP）

平台 → 动环设备 → 新建设备，支持温湿度/烟感/水浸/UPS 等类型：
1. 填写 Modbus 网关的 `IP + 端口 + 从站地址`（三者共同定位一台设备）
2. **传输协议**选一种（建设备表单里）：
   - `Modbus TCP（网关模式）` —— 串口服务器工作在「Modbus TCP 网关」模式，平台发标准 Modbus TCP 帧（带 MBAP 头、无 CRC）。
   - `RTU over TCP（透传/串口服务器）` —— 串口服务器工作在「透明传输 / TCP Server」模式，它把收到的字节**原样**转发到 485 总线。这种模式下标准 Modbus TCP 帧 RTU 设备不认识，表现就是 **TCP 能连上但任何读请求都超时**。这时必须选「RTU over TCP」，平台改发裸 RTU 帧（从站号+功能码+数据+CRC16、无 MBAP），网关透传后设备才有应答。
3. 按类型自动预置点位，也可手动增删点位（寄存器地址/功能码/系数）
4. 用「试读」验证单个点位配置，无误后「立即轮询」读全量
5. 平台按设备轮询间隔主动采集，只发读功能码（01/02/03/04），绝不下写

> **怎么判断该选哪个？** 先 `telnet <IP> <端口>` 确认 TCP 能连上，再跑探测脚本：
> `python tools/probe_modbus.py --dev <IP>:<端口> --scan-slave`
> 若四类功能码**全部超时**，多半是网关在透传模式，加上 `--rtu` 再跑：
> `python tools/probe_modbus.py --dev <IP>:<端口> --rtu --scan-slave`
> 一旦出数，就在平台把该设备「传输协议」改成 `RTU over TCP（透传/串口服务器）`。

> 旧版「温湿度监控」（HTTP 被动推送 `/api/env/{id}/push`）已下线，
> 统一由动环设备的 Modbus 主动采集替代；仪表盘的温湿度卡片已改为动环设备概览。

## 八、千问大模型接入

平台通过 OpenAI 兼容 API 对接内网千问模型，支持：
- vLLM 部署
- Ollama 部署（`ollama serve` + qwen2.5模型）
- Xinference 部署

配置 `.env` 中的 `LLM_BASE_URL` 指向模型服务地址即可。

功能：
- AI助手对话（自动注入当前监控数据上下文）
- 告警智能分析（一键分析告警原因和排查步骤）

## 九、告警规则

| 指标 | 警告阈值 | 严重阈值 |
|------|---------|---------|
| CPU使用率 | 80% | 95% |
| 内存使用率 | 85% | 95% |
| 磁盘使用率 | 85% | 95% |
| 机房温度 | 30°C | 35°C |
| 机房湿度 | <30% 或 >70% | <20% 或 >80% |
